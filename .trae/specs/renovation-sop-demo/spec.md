# 我的宝贝房子 DEMO - 产品需求文档

## Overview
- **Summary**: 一款面向半包装修新手的现代中式通关指南Web应用，以水墨年兽为引导角色，通过对话流风格探测、线性SOP流程、动态预算管理和游戏化养成系统，帮助用户在5分钟内完成核心装修体验闭环。
- **Purpose**: 解决半包业主装修流程不清晰、预算超支、材料采购混乱、合同陷阱等核心痛点，通过AI辅助和游戏化设计降低装修门槛和焦虑。
- **Target Users**: 25-35岁首次装修的年轻业主，选择半包模式（装修公司负责施工+辅材，业主自购主材）

## Goals
- 完成对话流风格探测（5题）+ 基础信息采集，生成个性化装修计划
- 实现半包SOP 6大阶段20步强制解锁流程，嵌入AI触发点
- 实现动态预算管理（532拆解、阶段释放、健康度仪表盘）
- 实现水墨年兽养成系统（5级成长、6阶段房子进化、情绪系统）
- 实现一键演示模式（6章4分钟自动播放）
- 响应式适配PC/平板/移动端
- 纯前端实现，所有AI功能用预置数据+动画模拟

## Non-Goals (Out of Scope)
- 不实现真实后端API和数据库
- 不实现全包/清包装修模式
- 不实现多风格自由选择（DEMO默认现代中式）
- 不实现真实AI模型调用（全部模拟）
- 不实现社交裂变传播机制
- 不实现用户账号系统和多人协作

## Background & Context
- 73%的半包业主无法准确预估材料用量
- 68%的装修纠纷源于增项未提前告知
- 28%平均超支比例，68%业主最终结算超预算15%以上
- 127小时比价平均耗时
- 设计风格：新中式扁平卡通，低饱和度暖色调
- 技术栈：React 18+ + Tailwind CSS + GSAP + Canvas

## Functional Requirements

### FR-1: 对话流风格探测与需求采集
- 水墨年兽引导的对话式交互界面
- 5题风格探测（客厅视觉、颜色偏好、生活方式、材质选择、最终二选一）
- 风格结果计算与展示（匹配度、标签、描述）
- 基础信息采集（预算、城市、面积、特殊需求）
- AI户型图识别模拟（上传动画+预置结果）
- 渐进式披露，每答2-3题给阶段性反馈

### FR-2: 半包SOP流程（强制解锁）
- 6大阶段20步线性SOP时间线
- 每步五步闭环：年兽引导→操作指引→AI辅助→完成确认→年兽反馈
- AI自动触发点：量房(户型识别)、签合同(合同鉴别)、4个验收节点(施工质检)
- 主材采购提醒机制（各阶段提前提醒）
- 现代中式风格施工注意点提示

### FR-3: 半包动态预算管理
- 智能预算拆解引擎（532原则：硬装50%、主材30%、备用20%）
- 城市系数调整（一线+15%、新一线基准、二三线-10%）
- SOP联动预算释放（6阶段按比例释放）
- 主材采购预算追踪（瓷砖/地板/橱柜/木门/洁具）
- 增项预警防火墙（10%上限、90%预警、书面确认）
- 铜钱形状预算健康度仪表盘（健康/预警/危险三态）

### FR-4: 水墨年兽养成系统
- 年兽5级成长体系（懵懂幼兽→红绸少年→玉佩童子→云纹使者→守护灵兽）
- 中式房子6阶段进化（毛坯空房→现代中式雅居）
- 年兽情绪系统（开心/打盹/困惑）
- 互动动作（点击作揖、长按查看属性）
- 成长数值体系（灵气值、装修玉石、房子评分、连续签到）
- 装备进阶展示

### FR-5: 演示模式（评委向导）
- 一键启动4分钟自动演示
- 6章脚本：开场Hook→对话流→SOP+AI→预算→年兽→收尾CTA
- Spotlight高亮+解说Tooltip
- 顶部进度条与章节标签
- 演示结束后保留数据供手动探索
- 右下角浮动入口球

### FR-6: 全局导航与视图切换
- 单页应用，状态机切换视图
- PC端左侧垂直导航栏
- 移动端底部Tab导航
- 5个主视图：引导/风格探测、SOP流程、预算管理、年兽养成、演示模式

## Non-Functional Requirements
- **NFR-1**: 首屏加载时间 < 2秒
- **NFR-2**: 页面切换动画 < 300ms
- **NFR-3**: 水墨粒子效果PC端60fps，移动端30fps（降级为CSS动画）
- **NFR-4**: 响应式适配PC(>=1024px)、平板(768-1024px)、移动端(<768px)
- **NFR-5**: 使用localStorage持久化用户进度，刷新不丢失
- **NFR-6**: 5分钟内完成核心闭环体验（风格探测→SOP步骤3完成）

## Constraints
- **Technical**: React 18+、Tailwind CSS、GSAP、Canvas、纯前端无后端
- **Business**: DEMO版，固定半包模式、固定现代中式风格、强制线性流程
- **Dependencies**: 预置Mock数据、无外部API依赖

## Assumptions
- 用户使用现代浏览器（Chrome/Firefox/Safari最新版）
- DEMO所有AI功能使用预置数据模拟，用户理解这是演示
- 预算计算基于行业平均水平，仅供参考
- 年兽和房子场景使用CSS+Canvas实现，无需3D引擎

## Acceptance Criteria

### AC-1: 对话流风格探测完整交互
- **Given**: 用户首次进入应用
- **When**: 用户依次完成5道风格探测题
- **Then**: 系统计算并展示风格结果（现代中式，87%匹配度，4个标签，描述文字），点击确认后进入基础信息采集
- **Verification**: `programmatic`

### AC-2: 基础信息采集完整流程
- **Given**: 用户完成风格探测
- **When**: 用户依次选择预算区间、城市、房屋面积、特殊需求，并完成户型图识别模拟
- **Then**: 系统生成半包计划，自动进入SOP流程，步骤1标记为已完成
- **Verification**: `programmatic`

### AC-3: SOP 20步强制解锁逻辑
- **Given**: 用户进入SOP流程
- **When**: 用户按顺序完成每个步骤
- **Then**: 已完成步骤显示竹青色，当前步骤黛蓝色脉冲，未来步骤灰色锁定；只能进入下一个未完成步骤，不可跳步
- **Verification**: `programmatic`

### AC-4: AI户型识别模拟
- **Given**: 用户在SOP步骤1（量房沟通）
- **When**: 系统自动触发AI户型识别
- **Then**: 显示上传动画→水墨晕染加载→识别结果（房间数、面积），自动填充数据
- **Verification**: `programmatic`

### AC-5: AI合同鉴别强制触发
- **Given**: 用户到达SOP步骤3（签订半包合同）
- **When**: 系统强制触发合同鉴别，不完成无法继续
- **Then**: 显示模拟扫描动画→风险检测结果→建议，用户确认后才能继续
- **Verification**: `programmatic`

### AC-6: AI施工质检触发
- **Given**: 用户到达验收节点（步骤10/12/13/15）
- **When**: 系统自动触发AI施工质检
- **Then**: 显示预置照片→模拟检测报告→验收结果，用户确认后完成步骤
- **Verification**: `programmatic`

### AC-7: 预算智能拆解
- **Given**: 用户输入总预算和城市
- **When**: 进入预算管理页面
- **Then**: 系统按532原则自动拆解预算（硬装50%、主材30%、备用20%），应用城市系数调整
- **Verification**: `programmatic`

### AC-8: 阶段预算释放与SOP联动
- **Given**: 用户有预算计划
- **When**: 完成一个SOP阶段
- **Then**: 对应阶段的预算池自动解锁，未解锁预算不可使用
- **Verification**: `programmatic`

### AC-9: 预算健康度仪表盘
- **Given**: 用户进入预算页面
- **When**: 查看预算健康度
- **Then**: 铜钱形状进度环显示各阶段消耗，中心年兽表情随健康度变化（健康/预警/危险）
- **Verification**: `human-judgment`

### AC-10: 年兽5级成长体系
- **Given**: 用户完成不同数量的SOP步骤
- **When**: 年兽达到等级阈值（LV.1/6/12/18/24）
- **Then**: 年兽外观变化，获得对应装备（无/红绸带/玉佩/云纹披风/金铃）
- **Verification**: `human-judgment`

### AC-11: 房子6阶段进化
- **Given**: 用户完成不同SOP阶段
- **When**: 进入年兽养成页面
- **Then**: 房子场景显示当前阶段对应的装修状态和家具
- **Verification**: `human-judgment`

### AC-12: 年兽情绪反馈
- **Given**: 不同的应用状态
- **When**: 预算健康/预警/危险，或进度正常/延误
- **Then**: 年兽表情相应变化（开心/困惑/打盹）
- **Verification**: `human-judgment`

### AC-13: 演示模式完整播放
- **Given**: 用户点击一键演示
- **When**: 演示自动播放
- **Then**: 4分钟内完成6章演示，每章有Spotlight高亮和解说，顶部显示进度条
- **Verification**: `programmatic`

### AC-14: 响应式布局
- **Given**: 不同屏幕尺寸
- **When**: 调整窗口大小
- **Then**: PC端左侧导航、移动端底部Tab，内容自适应排列
- **Verification**: `human-judgment`

### AC-15: 状态持久化
- **Given**: 用户有操作进度
- **When**: 刷新页面
- **Then**: 进度数据从localStorage恢复，用户从离开处继续
- **Verification**: `programmatic`

### AC-16: 设计规范一致性
- **Given**: 所有页面
- **When**: 查看UI
- **Then**: 所有颜色/字体/间距/圆角遵循设计系统规范，新中式扁平卡通风格统一
- **Verification**: `human-judgment`
